> 基于 MediaPipe 的智能抠图工具，支持 AI 自动抠图和颜色抠图两种模式

## ✨ 功能特性

- ✅ **AI 自动抠图** - 基于 MediaPipe DeepLab V3 模型，智能识别前景和背景
- ✅ **颜色抠图** - 通过拾取颜色实现精确抠图
- ✅ **多图片管理** - 支持同时处理多张图片
- ✅ **参数调节** - 丰富的参数选项，满足不同场景需求
- ✅ **画布操作** - 支持缩放、平移等操作
- ✅ **批量上传** - 支持拖拽和点击上传
- ✅ **实时预览** - 即时查看处理效果

## 📸 使用方法

### 安装插件

**方式 1：开发模式加载（推荐）**

1. 克隆项目并安装依赖

   ```bash
   pnpm install
   pnpm run add-electron-types
   ```

2. 运行开发模式

   ```bash
   pnpm run dev
   ```

3. dist 目录路径会自动复制到剪贴板
4. 打开 Naimo 搜索框，粘贴路径即可载入插件

**方式 2：从 GitHub 安装**

1. 从 GitHub build 分支下载插件包
2. 解压到 Naimo Tools 的 `plugins` 目录
3. 重启 Naimo Tools

### 触发插件

- 输入关键词触发（如：`AI 抠图`、`去背景`）
- 拖入图片文件触发

### 使用步骤

#### 1. 上传图片

- 点击左侧上传区域选择图片
- 或直接拖拽图片到上传区域
- 支持 JPG、PNG、WEBP 格式

#### 2. 选择抠图模式

**AI 抠图模式：**

- 自动识别前景和背景
- 适合人像、物体等主体明确的图片
- 可调节分割阈值、边缘羽化等参数

**颜色抠图模式：**

- 点击"拾取颜色"按钮
- 在画布上点击要去除的颜色
- 可拾取多个颜色
- 调节颜色相似度控制去除范围

#### 3. 调整参数

**AI 抠图参数：**

- **分割阈值**：控制前景/背景分离程度（0-1）
- **边缘羽化**：软化边缘，使抠图更自然（0-10px）
- **边缘调整**：收缩或扩展边缘（-5 到 5px）
- **边缘清洁**：清理边缘噪点（0-20px）
- **边缘透明度**：调整边缘透明度（0-100%）

**颜色抠图参数：**

- **颜色相似度**：控制颜色匹配范围（0-100）
- **边缘羽化**：软化边缘（0-20px）
- **边缘膨胀**：收缩或扩展边缘（-10 到 10px）
- **抠图模式**：移除或保留选中颜色

#### 4. 处理图片

- 点击"开始处理"按钮
- 等待处理完成

#### 5. 下载结果

- 点击"下载"按钮
- 图片将以 PNG 格式保存（支持透明背景）

### 画布操作

- **缩放**：鼠标滚轮
- **平移**：鼠标拖拽
- **重置**：点击"重置图片"按钮

## 📝 开发说明

### 组件架构

**ImageList（图片列表）：**

- 负责图片上传和列表管理
- 使用 `object-fit: cover` 显示预览图
- 支持拖拽上传和删除

**Canvas（画布）：**

- 负责图片显示和处理
- 支持缩放、平移操作
- 处理颜色拾取事件

**ControlPanel（控制面板）：**

- 提供两种抠图模式的参数控制
- 管理颜色拾取列表
- 实时更新参数

### 工具函数

**mediapipe.ts：**

- 初始化 MediaPipe 模型
- 处理模型加载失败情况

**image-processing.ts：**

- AI 抠图核心算法
- 颜色抠图核心算法
- 图像滤镜函数（高斯模糊、形态学操作等）

## 🎨 优化点

### 相比原始 HTML 版本的改进

1. **使用 Vue 组件化**

   - 代码结构更清晰
   - 易于维护和扩展
   - 组件复用性强

2. **画布支持缩放平移**

   - 鼠标滚轮缩放
   - 拖拽平移
   - 提升用户体验

3. **图片列表优化**

   - 使用 `cover` 模式显示预览
   - 图片完整展示，无变形
   - 支持删除和选择

4. **极大利用空间**

   - 三栏布局充分利用屏幕空间
   - 组件高度自适应
   - 滚动优化

5. **SVG 图标**
   - 使用矢量图标
   - 清晰锐利
   - 支持主题定制

## ⚠️ 注意事项

1. **模型加载**

   - 首次使用需下载 AI 模型（约 40MB）
   - 需要网络连接
   - 加载失败可使用颜色抠图模式

2. **浏览器兼容性**

   - 需要支持 WebAssembly
   - Chrome 67+
   - Firefox 60+
   - Safari 11+
   - Edge 79+

3. **性能优化**
   - 大图片会自动缩放到 512x512 处理
   - 避免同时处理过多图片
   - 建议图片大小 < 5MB
